# Ask what needs admin attention

[← MCP guides](README.md) · **Who:** Authorised administrators

**Try:**

> Use $tzh-admin-attention to show admin work due today. Include overdue work, undated backlog and coverage. Do not change anything or send messages.

1. Check the resolved Malaysia date range and as-of time.
2. Read **overdue**, **due in window** and **undated backlog** separately, plus the overall counts and exclusions.
3. Follow a returned website link to handle its receipt, claim, trial, attendance or other supported action in the normal screen.
4. Ask again after completing work; resolved items leave the live result.

You can ask for tomorrow, this week (Monday–Sunday), or an explicit date range up to 31 days. If more results exist, ask for the next page with the same filters.

**Expected:** `query_admin_attention` reads only. It does not approve receipts, send reminders, record attendance or create a scheduled chat. Zero items due today is not an all-clear if overdue/undated work remains. A failed provider is an error, not an empty queue.
