# MCP · Use the Codex assistant

[← Overview](../overview.md)

Start with [access and setup](getting-started.md), then choose a task:

| Task | Guide | Permission |
|---|---|---|
| Read current admin work | [Admin attention](admin-attention.md) | Read admin attention |
| Reconcile historical student accounts | [Student audit](student-audit.md) | Student account |
| Award positive member points | [Point assignment](points.md) | Member points |
| Change concrete lesson duration/price | [Lesson changes](lesson-management.md) | Lesson management |
| Query or record attendance | [Attendance](attendance.md) | Lesson management |
| Create already-paid manual invoices | [Manual invoices](manual-invoices.md) | Manual invoices |

[Function reference](functions.md) lists the exact names and purpose of every current server function, including invoice compatibility tools.

Ask in ordinary language, identify the right person/lesson, then inspect the result. **Preparing a preview is not approval to save it.** Explicitly approve the complete displayed preview only after checking it. “Continue” or silence is not approval. If a result is uncertain, ask the assistant to check/retry that same approved operation; do not create another one.

The assistant uses only the authorised MCP connection for private TZH records. It must report missing tools/permissions rather than bypassing them. Examples below use fictional names; replace them with your intended records in your private connected workspace.
